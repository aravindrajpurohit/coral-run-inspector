Relative cost, Value = 1

Read

  • Fast costs 2.22x Value and runs about 3.7x faster (449 vs 121 tok/s). Worth it when a user is waiting on the agent.
  • Standard costs 1.86x Value but runs at Value's speed (130 tok/s). Its cheaper output is offset by $0.19/M input and charged cache reads, which hurt when most of the input is cache.
  • Fast for interactive, Value for background. Standard rarely wins this workload shape.

Workload-specific: on a low-cache or output-light workload the input and cache penalties shrink and the ranking shifts.
